An entry for the [One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc) competition on [make.fun](https://make.fun).

## What it does

`main.ts` writes a single original one-line office joke (under 200 characters) to `/output/entry.txt`:

> The office printer has exactly two moods: out of toner, and jammed on the only page I actually needed.

## Run

```sh
node main.ts
```

The program is deterministic: every run writes the exact same bytes. It needs no input, no network, and no secrets.
